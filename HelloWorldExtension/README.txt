MANIFEST - manifest.json: Extension capabilities + core config + basic metadata
- the only required file for extensions
- must be in root dir of extension
- "action" key = extension action icon + HTML popup when clicked
    - HTML popup uses popup.js for console logging with the popup (can view log by "inspect" the popup in browser)

Chrome Extensions page: manage extensions, reload, view errors, etc
